# Go-live checklist — Bridge to Sentience commune

Use before declaring the commune “in production.” Prefer same week as workshop.

## Authority
- [ ] Accountable Human named and reachable
- [ ] R3 approver list documented
- [ ] Licence acknowledged (single organization)

## Artifacts
- [ ] Census complete with no blank owned outcomes
- [ ] Briefs for every Keep agent
- [ ] Charter signed
- [ ] Scoreboard baseline dated
- [ ] Witness channel/path created

## Gates
- [ ] Spend policy adopted or dated adoption plan ≤14 days
- [ ] Disclosure policy reviewed for live human channels
- [ ] Embodiment policy acknowledged (even if Stage <4)

## Cadence
- [ ] First war room scheduled **or** quiet-skip rule written
- [ ] Monthly delete pass on calendar
- [ ] Memory purge owner named

## Epistemic
- [ ] Team can label OBSERVED/ENGINEERED/REPORTED/MYTH
- [ ] Marketing/public claim review path agreed
