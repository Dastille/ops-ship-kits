# Delete pass — Enterprise Agent Fleet OS

Run before adding another agent seat. Goal: fewer overlapping bots, one accountable human, one north star.

## Setup (15 min)
- [ ] Fleet Accountable Human named: ____________
- [ ] Inventory list open (name, owner, cost/mo, owned outcome)
- [ ] North star outcome written in one sentence: ____________

## For each agent / bot / automation

## Kill rules (use any one)
- No named owner → Kill or assign in 7 days
- No owned outcome in one sentence → Kill
- Duplicate of a Keep agent → Merge or Kill
- Quiet for 30+ days with no scored result → Kill
- Irreversible actions without a human gate → Pause until gated
